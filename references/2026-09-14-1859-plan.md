# Plano: conversão de `extract-meteo-br` em pacote R

## Estado atual (diagnóstico)

Projeto de análise (não é pacote) com boa maturidade de código:

- `R/` (8 arquivos, ~1.300 linhas): `aggregate-monthly.R`, `area-weighted-mean.R`,
  `crop-netcdfs.R`, `fill-missing-raster-cells.R`, `geographic-data.R`,
  `interactive-maps.R`, `municipal-output.R`, `run-pipeline.R`. Funções já
  documentadas com roxygen2 (`@param`, `@return`, `@export`), validação com
  `checkmate`, e chamadas com namespace explícito (`pkg::fn()`) — não usam
  `library()` dentro das funções. Isso reduz bastante o esforço de conversão.
- `scripts/` (6 arquivos numerados `00`–`04` + `run-meteo-pipeline.R`): scripts
  procedurais que fazem `source()` dos arquivos em `R/` e dependem de objetos
  em `.GlobalEnv` (`municipalities`, `monthly_rasters`, `filled_monthly_rasters`).
  `run_meteo_pipeline()` (em `R/run-pipeline.R`) já encapsula esse fluxo como
  função única — os scripts `01`–`04` são, na prática, redundantes com ela.
- `tests/testthat/test-area-weighted-mean.R`: já usa `testthat`/`test_that()`,
  mas falta o runner (`tests/testthat.R`) e infraestrutura padrão de pacote.
- `inst/ext/`: dados brutos externos (NetCDFs BR-DWGD, shapefiles IBGE) —
  potencialmente muito grandes para viver dentro de um pacote distribuído.
- `inst/validation/`: scripts de validação com dados reais, não fazem parte
  da suíte automática de testes.
- `data/processed/`: saídas `.fst` (9–22 MB) geradas pelo pipeline — não são
  dados de pacote (`data/*.rda`), são artefatos de execução.
- Não existem `DESCRIPTION`, `NAMESPACE`, `.Rbuildignore`, `man/`, `renv.lock`,
  nem repositório git inicializado.
- Vários defaults de argumento usam `here::here("inst/ext/...")` — isso só
  funciona dentro do projeto-fonte; não funciona depois de instalado como
  pacote (`here::here()` resolve para o diretório de trabalho do usuário, não
  para o pacote instalado).
- Pacotes usados: `checkmate`, `fs`, `purrr`, `stringr`, `terra`, `lubridate`,
  `cli`, `here`, `tibble`, `data.table`, `Matrix`, `sf`, `dplyr`, `tmap`,
  `fst`, `tictoc`.

## Decisões confirmadas

1. **Nome do pacote**: `extractmeteobr`.
2. **Dados externos (`inst/ext/`)**: removidos do pacote. Argumentos de
   caminho (`monthly_data_path`, `municipality_data_path`, etc.) passam a ser
   **obrigatórios**, sem default apontando para `inst/ext/...`. Os dados
   continuam existindo no repositório-fonte (fora da árvore instalável do
   pacote, via `.Rbuildignore`), mas o usuário deve fornecer os caminhos
   explicitamente ao chamar as funções.
3. **Scripts numerados (`scripts/00`–`04`)**: convertidos em uma vignette
   (`vignettes/pipeline.Rmd`) que documenta o fluxo completo via
   `run_meteo_pipeline()` (e `aggregate_daily_netcdfs_by_month()` para a
   etapa 0). Os scripts numerados originais saem da árvore do pacote.
4. **`tmap`**: declarado em `Suggests` (não `Imports`); `make_interactive_spatial_map()`
   passa a validar a disponibilidade do pacote com
   `rlang::check_installed("tmap")` (ou `requireNamespace("tmap", quietly = TRUE)`
   com `cli::cli_abort()` se ausente) antes de usá-lo.
5. **Licença**: MIT (`usethis`-style `LICENSE` + `LICENSE.md`, ou entrada
   manual `MIT + file LICENSE` no `DESCRIPTION`).
6. **`inst/validation/`**: mantido como está por ora (scripts avulsos com
   dados reais, não executados em `R CMD check`); não será tratado nesta
   rodada de conversão.
7. **Git**: fora de escopo desta conversão; não será inicializado
   automaticamente.

## Execução concluída

Todos os itens do plano foram implementados. Resumo do que foi feito e das
descobertas relevantes durante a execução:

- `DESCRIPTION`, `NAMESPACE` (via `roxygen2::roxygenise()`), `man/*.Rd`,
  `.Rbuildignore`, `LICENSE`/`LICENSE.md` (MIT) criados.
- Removidos todos os defaults `here::here("inst/ext/...")` em
  `aggregate_daily_netcdfs_by_month()`, `load_ibge_municipalities()`,
  `load_ibge_states()`, `join_and_write_municipal_means()`, e
  `run_meteo_pipeline()`; os caminhos correspondentes (`data_path`,
  `monthly_data_path`, `municipality_data_path`, `output_dir`) passaram a ser
  obrigatórios. **Descoberta**: o default antigo de
  `aggregate_daily_netcdfs_by_month()` apontava para
  `inst/ext/br-dwg/...` (faltando o "d"), um caminho inexistente — o diretório
  real é `inst/ext/br-dwgd/...`. Removido junto com os demais defaults.
- Removido o parâmetro morto `output_path` de `extract_area_weighted_mean()`
  (tinha default `here::here(...)` e não era usado no corpo da função).
- `make_interactive_spatial_map()` agora valida `tmap` com
  `requireNamespace()` e `cli::cli_abort()`; `tmap` passou para `Suggests`.
- Adicionado `.datatable.aware <- TRUE` em `R/area-weighted-mean.R`: sem essa
  declaração, `make_polygon_cell_weights()` falhava em tempo de execução
  dentro do pacote (erro de `data.table` sobre `:=` fora de um ambiente
  "data.table-aware").
- Adicionado `R/extractmeteobr-package.R` com `utils::globalVariables()` para
  eliminar a única NOTE de `R CMD check` (variáveis de coluna referenciadas
  por NSE em `data.table`/`dplyr`).
- **Descoberta importante**: `tests/testthat/test-area-weighted-mean.R`
  estava dessincronizado da implementação atual — chamava
  `make_polygon_cell_weights(r=, id_col=)`,
  `area_weighted_mean_by_polygon()` e
  `extract_area_weighted_mean(r_list=, cell_weights=)`, nomes/parâmetros que
  não existem mais (atuais: `make_polygon_cell_weights(raster=, polygon_ids=)`,
  `calculate_area_weighted_mean()`, `extract_area_weighted_mean(rasters=)`
  sem reuso de `cell_weights`), e a tabela de pesos usa `area_weight` fundido
  em vez de `fraction`/`cell_area` separados. Reescrevi o arquivo de teste
  para usar a API atual, preservando integralmente a lógica de validação
  científica (mesma fórmula, mesmos casos de borda); a checagem de interseção
  parcial passou a usar `terra::extract(..., exact = TRUE)` diretamente, sem
  depender do formato interno de `make_polygon_cell_weights()`. Os 14 testes
  agora passam.
- `README.Rmd` também estava dessincronizado: referenciava scripts e nomes de
  função que não existem mais (`R/00-aggregate-monthly.R`, `load_municipios()`,
  `crop_monthly_data()`, `fill_na_focal_idw()`,
  `area_weighted_mean_by_polygon()`, argumento inexistente `min_coverage`).
  Atualizado para refletir a instalação como pacote, os nomes de arquivo/
  função atuais, e a vignette do pipeline.
- `scripts/` removido (conteúdo preservado em `vignettes/pipeline.Rmd`,
  conforme decisão aprovada).
- `README.md`/`README.html` regenerados; artefato `README.html` (subproduto
  do `rmarkdown::render()`) removido do diretório e adicionado ao
  `.gitignore`, junto com outras entradas padrão (`.Rhistory`, `.RData`,
  `inst/doc`).
- `devtools::check()` final: **0 erros, 0 avisos, 0 notas**.
